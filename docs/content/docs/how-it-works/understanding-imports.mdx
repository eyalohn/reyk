---
title: Understanding Python Imports
---

`pyisolate` leverages Python's import system internals to achieve transparent dependency isolation.

1. **Detects** whether an import originates from within your package
2. **Checks** for a vendored version of the requested module
3. **Redirects** the import when appropriate
